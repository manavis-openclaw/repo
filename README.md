# manabin-server-notes

Maintenance ledger for the Manabin server.

## Purpose

This repository stores non-secret operational notes needed for maintenance,
recovery, and rebuild work.

## Rules

- Do not store secrets directly in this repository.
- Store actual tokens, passwords, and private keys in a password manager.
- Use this repository to record locations, procedures, dependencies, and checklists.

## Recommended fill order

1. `server-info.md`
2. `access-and-network.md`
3. `openclaw.md`
4. `operations.md`
5. `backup-and-restore.md`
6. `rebuild-checklist.md`
7. `secrets-reference.md`
